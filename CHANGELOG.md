📌 Change Format

When making a significant system change, use:

# [VERSION] — YYYY-MM-DD

## Added
- New system
- New folder
- New template

## Changed
- Modified workflow
- Updated structure
- Improved documentation

## Removed
- Deleted folder
- Removed workflow

## Fixed
- Corrected organization
- Fixed broken references

## Deprecated
- System no longer recommended

## Notes
- Reason for major changes
🔢 Versioning

Use:

MAJOR.MINOR.PATCH
MAJOR

Major restructuring.

Example:

1.0.0 → 2.0.0
MINOR

New systems or significant features.

Example:

1.0.0 → 1.1.0
PATCH

Small fixes and documentation improvements.

Example:

1.1.0 → 1.1.1
